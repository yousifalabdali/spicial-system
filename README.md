# Sales Inventory Pro

نظام داخلي لإدارة المبيعات والمخزون، يعمل على **ماك** و**ويندوز** بدون إنترنت. البيانات تُحفظ على جهاز المحل نفسه.

## المميزات
- **الرئيسية**: ملخص المبيعات والتحصيلات والمصروفات والأرباح، مع آخر الفواتير وتنبيهات النظام ورسوم بيانية
- **المبيعات**: نقطة بيع سريعة (بحث بالاسم أو الكود، ويدعم قارئ الباركود)، وسجل الفواتير مع التحصيل والإلغاء، وإدارة العملاء
- **المخزون**: إضافة الأصناف وتعديلها، وتنبيه عند انخفاض الكمية
- **الخزينة**: القبض والصرف والمصروفات، ومتابعة الشيكات
- **الموردين**: أوامر الشراء، واستلامها لتُضاف إلى المخزون، وتسديد المستحقات
- **التقارير**: المبيعات والأرباح حسب الفترة، والأصناف الأكثر مبيعاً، وتقرير المخزون، مع تصدير إلى Excel (CSV)
- **الطباعة**: فاتورة على طابعة حرارية 80mm أو على ورق A4، أو حفظها كملف PDF
- **العملة**: الريال العماني بثلاث خانات عشرية، وضريبة قيمة مضافة 5% يمكن تعديلها أو إيقافها

## التثبيت على جهاز المحل

ملفات التثبيت تُنتج في مجلد `release/`.

### ماك
1. افتح الملف `Sales Inventory Pro-1.0.0-arm64.dmg` (لأجهزة Apple M1 وما بعدها) أو `...-x64.dmg` (لأجهزة Intel).
2. اسحب التطبيق إلى مجلد **Applications**.
3. عند أول تشغيل: اضغط على التطبيق بالزر الأيمن ثم اختر **Open**، ثم **Open** مرة أخرى. هذا مطلوب لأن التطبيق غير موقّع من Apple.
   إذا ظهرت رسالة أن التطبيق «تالف»، شغّل الأمر التالي في Terminal:
   `xattr -cr "/Applications/Sales Inventory Pro.app"`

### ويندوز
1. شغّل الملف `Sales Inventory Pro-Setup-1.0.0.exe`.
2. إذا ظهرت نافذة «Windows protected your PC»، اضغط **More info** ثم **Run anyway**.
3. أكمل التثبيت. سيظهر اختصار للبرنامج على سطح المكتب.

### أول تشغيل
- يفتح البرنامج ومعه **بيانات تجريبية** لتتعرف عليه.
- عندما تكون جاهزاً لبدء العمل الفعلي: من **الإعدادات** اختر **مسح جميع البيانات**، ثم أدخل بيانات المحل والطابعة وأصنافك.

### مكان ملف البيانات (للنسخ الاحتياطي)
كل البيانات في ملف واحد اسمه `store.db`. انسخه مع الملفات المجاورة له (`store.db-wal` و`store.db-shm`) إلى فلاشة بعد إغلاق البرنامج:
- ماك: `~/Library/Application Support/sales-inventory-pro/`
- ويندوز: `%APPDATA%\sales-inventory-pro\`

## للمطوّر

```bash
npm install
npm run dev        # تشغيل أثناء التطوير
npm run dist:mac   # بناء ملفات dmg للماك
npm run dist:win   # بناء ملف exe للويندوز (يعمل من الماك أيضاً)
```

التقنيات المستخدمة: Electron وReact وTypeScript وTailwind وSQLite (better-sqlite3).

إذا فشل بناء الويندوز من الماك: ارفع المشروع إلى GitHub وشغّل workflow **build** من تبويب Actions. سيبني ملفات التثبيت على أجهزة ويندوز وماك حقيقية.

## الموقع (Vercel + Supabase) والصلاحيات

النظام موقع ويب، وبياناته في **Supabase** (قاعدة Postgres). تطبيق سطح المكتب يفتح الموقع نفسه ويضيف الطباعة المباشرة والنسخ الاحتياطي إلى مجلد على الجهاز.

| الدور | ماذا يستطيع |
|---|---|
| سوبر أدمن | كل شيء، وهو الوحيد الذي يمنح الصلاحيات ويسحبها ويغيّر الأدوار ويحذف الحسابات، والنسخ الاحتياطي والاستعادة |
| أدمن | الصفحات التي منحها له السوبر أدمن، وإضافة الموظفين وإيقافهم وإعادة كلمات مرورهم |
| موظف | الصفحات التي مُنحت له فقط (افتراضياً: الرئيسية والمبيعات) |

الصلاحيات تُفحص في الخادم مع كل طلب، فسحب صلاحية أو إيقاف حساب يسري فوراً.

### النشر خطوة بخطوة

**1. Supabase**
1. أنشئ مشروعاً على [supabase.com](https://supabase.com).
2. من **Project Settings → Database → Connection string** اختر **Transaction pooler** (المنفذ 6543) وانسخ الرابط، وضع كلمة مرور قاعدة البيانات مكان `[YOUR-PASSWORD]`.
3. لا تحتاج إنشاء جداول: الموقع ينشئها عند أول طلب، ويفعّل عليها RLS حتى لا تُقرأ من واجهة Supabase العامة.

**2. Vercel**
1. على [vercel.com](https://vercel.com): **Add New → Project** واستورد هذا المستودع، واختر الفرع المطلوب.
2. في **Environment Variables** أضف:

| المتغيّر | القيمة |
|---|---|
| `DATABASE_URL` | رابط Supabase من الخطوة السابقة |
| `SETUP_CODE` | رمز سري تختاره أنت (مثل 8 أحرف عشوائية)، تحتاجه مرة واحدة لإنشاء حساب السوبر أدمن |
| `APP_TIMEZONE` | اختياري، الافتراضي `Asia/Muscat` |

3. اضغط **Deploy**، ثم افتح رابط الموقع وأنشئ حساب السوبر أدمن بالرمز.

لا تضع هذه القيم في الكود أو في GitHub: مكانها إعدادات Vercel فقط.

**3. تطبيق سطح المكتب**
عند أول تشغيل يطلب عنوان الموقع (رابط Vercel). بعدها يفتح الموقع مباشرة، ويطبع على الطابعة المختارة في الإعدادات، ويحفظ نسخة احتياطية في مجلد على الجهاز حسب الجدول في **لوحة التحكم** (يعمل والبرنامج مفتوح بحساب سوبر أدمن).

### التشغيل على جهازك للتجربة (بدون Supabase)

```bash
npm install
npm run build && npm run build:server
SEED_DEMO=1 node dist-server/index.cjs   # قاعدة Postgres محلية في ./data
```

يطبع الخادم **رمز الإعداد** في الطرفية. للاتصال بـ Supabase بدلاً من القاعدة المحلية أضف `DATABASE_URL=...`. انظر `.env.example`.
